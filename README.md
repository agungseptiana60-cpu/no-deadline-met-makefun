A one-line excuse for a missed deadline: I put the deadline on my to-do list right under 'buy milk' and 'call Mom' — I bought the milk, I called Mom, and the deadline is still waiting for its turn. The program in `main.ts` writes that single line (156 characters) to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
